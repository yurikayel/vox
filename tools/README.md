# tools/

**Ferramentas para quem usa ou opera o Vox** fora do navegador.

| Ferramenta | Para quê |
|---|---|
| [`posse-cli/`](./posse-cli/) | Reenvia um export de posts para webhooks (Discord, Slack, n8n…) pelo terminal |
| [`auto-explode/`](./auto-explode/) | Userscript **opcional** (Tampermonkey e similares) que confirma a publicação nas abas abertas pelo botão EXPLODE!, usando a sessão já logada da própria pessoa. Instalar é uma escolha explícita de quem usa |

Scripts de manutenção do repositório ficam em [`scripts/`](../scripts/); instaladores, em [`packaging/`](../packaging/).
