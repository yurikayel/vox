# Telas sem layout Stitch — prompts para gerar

> **Status:** canônico (prompts de tela; o que já foi aplicado está no ADR-016 §5) · **Owner:** mantenedor · **Revisado:** 2026-11-11

Design system: [sovereign-agora.md](./sovereign-agora.md) (*Sovereign Agora Luminescent Matrix*). O pacote de mockups `stitch_vox_civic_network_interface/` foi aplicado e removido do repositório em 2026-11; ele continua no histórico do git.
Telas já cobertas e aplicadas (ADR-016 §5): Ágora (feed desktop/mobile), Vote (desktop/mobile), Comunidades (lista desktop/mobile), Mensagens (desktop 2 colunas, mobile lista e conversa), Perfil (desktop/mobile), gaveta Identidade/Rede.

**Atualização 2026-11-11:** os prompts 1–3 abaixo (tópico, página da comunidade e pauta) viraram as telas 6–8 do segundo pacote Stitch e foram aplicados (ADR-016 §5.4). Do mesmo pacote, as telas 9–14 já tinham entrado no rework de 2026-11-07 (commit `59cd1fc`). Os prompts 4–12 continuam valendo para as telas que ainda não têm layout.

## Prefixo comum (cole antes de cada prompt)

> Use the existing "Sovereign Agora Luminescent Matrix" design system of the Vox project: OLED obsidian ground #0d0f12/#111316, travertine text #f4eedd/#e2dcce, consensus emerald #10b981/#34d399, attic cobalt #3b82f6, aurora gradient (135deg #10b981 → #06b6d4 → #3b82f6) only for primary actions, 1px entablature hairlines #232830 instead of cards, 4px radii (circles only for avatars/presence), Noto Serif for titles, Inter for UI, tabular numerals. Same app shell as the other Vox screens: left sidebar (VOX wordmark; Ágora, Vote, Comunidades, Mensagens, Perfil; Pessoas and Voxpedia as secondary; aurora "Postar" button) and a top bar with search, "Votar agora" and identity chip; on mobile a compact top bar, 5-item bottom nav and a floating "Postar" button. All UI copy in Brazilian Portuguese. Show only data a local-first app could really know — no invented treasuries, ZK proofs or vote counts. Deliver desktop (1440px) and mobile (390px).

## Prompts por tela

1. **Detalhe do tópico / thread (`#/t/:id`)** — "A discussion thread page: original post as a planar stele (author, community chip, time, serif title, body, media, action row: curtir, comentar, republicar, compartilhar, salvar, ⋯ menu), then nested replies up to 4 levels with thin left guide lines, 'Respondendo a @fulano' context, a sticky reply composer at the bottom, and a locked-topic notice state."
2. **Página da comunidade (`#/c/:id`)** — "A community home: header with square community avatar, serif name, pills (Aberta/Fechada, categoria, Oficial), member count, actions (Membro ✓ / Entrar, Compartilhar, Novo post), description and 'ficha' (dono, tipo, idioma); tabs Tópicos · Feira · Governança · Membros; topic list as hairline rows with sort tabs (Atividade recente, Mais recentes, Fixados), civic tag pills (Pauta, Ideia, Bug, Debate) and a 'Carregar tópicos anteriores (N)' button; a side panel 'Sustentada por vizinhos' showing devices online."
3. **Detalhe da pauta (`#/c/:id/proposal/:id`)** — "A governance proposal page: status pill, community, author, countdown, serif title, body, optional unified diff block (green/red lines), tally panel (sim/não/abstenção bar, quórum x/y, votos fora do corte anti-brigading), ballot with three buttons and a note explaining the eligibility cutoff, and an 'Ecoar' row (copiar resumo, webhook)."
4. **Compositores (`#/compose/topic`, `/proposal`, `/listing`, `/community`, reply)** — "A unified compose screen with a community picker pill, title and body fields on the planar surface (gradient underline on focus), civic tag chips, media attach (foto, áudio, vídeo) with preview, an 'Opções avançadas' drawer, and an aurora 'Publicar' button. Variants: new proposal (adds optional diff and closing date), marketplace listing (price, Pix key, photo), new community (name, id slug, photo, visibility)."
5. **Pessoas (`#/people`)** — "A people directory: page head with search/filter field, list of people as hairline rows (avatar, name, @handle, short id in mono, 'Você' badge) with actions Conectar, Mensagem, Ver perfil; empty and no-results states."
6. **Saúde do nó e rede (`#/status`, `#/settings/network`)** — "A local node health page: real metrics only (aparelhos conectados via WebRTC, relays alcançáveis, blobs servidos, cache usado/limite, modo somente leitura), a toggle matrix for network participation (participar da malha, limite de dados, só Wi-Fi), and a steward wizard entry card. Use telemetry styling with sparklines."
7. **Onboarding e entrada** — "First-run flow: (a) welcome gate with the VOX wordmark and one-line manifesto; (b) 'Como quer aparecer?' — name field, import name/photo from Google/Meta/GitHub, restore with 'Senha Soberana', and 'Pular — continuar só com vx_'; (c) the network participation pact with a clear accept button. Calm, legible, no dark patterns."
8. **Voxpedia (`#/voxpedia`)** — "A plain-language glossary: search field, alphabetical index, entries as serif term + one-paragraph explanation, related-term chips."
9. **Carteira / Pix (`#/wallet`, `#/pix/:chave`, modal de Zap)** — "A Pix tipping flow: profile Pix key (masked), amount chips, BR Code QR with copy-paste code, and a confirmation state; wallet page listing received/sent zaps stored locally."
10. **Compartilhar / POSSE** — "A share sheet modal (constitutional modal stele with aurora top stroke): canonical link copy, quick targets (WhatsApp, Telegram, Bluesky, X, Instagram story card), and a 'Postar & Ecoar' summary of where the post was syndicated."
11. **Tema claro** — "A light variant of the whole design system: travertine paper ground (#f4f0e8), obsidian text, emerald #047857 and cobalt #1d4ed8 accents with AA contrast, same hairline architecture. Show Ágora, Vote and Perfil."
12. **Estados globais** — "Loading skeletons, empty states, offline banner ('Sem internet — mostrando o que está neste aparelho'), error toast, and confirmation dialogs, all in the same system."
