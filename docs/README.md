## Como manter docs

Resumo — detalhes em [CONTRIBUTING-DOCS.md](./CONTRIBUTING-DOCS.md):

1. Só este README navega; links relativos in-repo.
2. Banner **Status · Owner · Revisado** em docs estratégicos; SHA/testes via README release.
3. Checklist: um DoD por item (`doc` | `code` | `ops-humano`).
4. Brainstorm novo: banner + “não substitui X”; sem N= mestre duplicado.
5. Mutex: um editor por arquivo canon por vez.
