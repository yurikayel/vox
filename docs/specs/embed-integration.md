Script estático: [`client/embed/vox-embed.js`](../../client/embed/vox-embed.js)

```html
<script
  src="https://yurikayel.github.io/vox/embed/vox-embed.js"
  data-topic="top_abc123"
  data-label="Comentar no Vox"
  data-ref="meu-blog"
  async
></script>
```
